# AI 研究流程增量更新

本轮仅使用公开框架、虚构园圃文字和独立测试账户。未读取真实书库、命例、私有规则或用户 API 密钥；未发起真实付费模型调用。

## 实现范围

- 书库页数检查增加逐页表，按指定页码返回最多 25 页元数据：保存、文字可检索、影像和校订。区分缺页与已保存但没有文字；不以页号或记录数证明 OCR 正确。
- 研究 Agent 可选单本公开材料，服务端在模型调用之前校验范围，禁止引用跨越选定材料。全部公开书库仍走关键词检索。
- 单本 Agent 可显式启用已有 multilingual-e5-small 本机向量搜索，与关键词候选通过 RRF 融合。下一次云端调用之前，服务端从仍公开的原页重建选段。没有引入 Qwen3 专用重排模型。
- 默认逐步确认，可主动选择最多四步自动继续。检索决定先保存检查点，再开始本机索引；索引中断后只重做本机步骤。正在发送但没有收到结果的云端请求不会自动重试，因为它可能已经计费。
- 加密研究记录使用浏览器互斥锁及记录版本检查，避免两个页面同时推进同一记录。未解锁不能继续保存。页面关闭会丢弃内存向量索引，恢复时重新建立；不是索引逐块持久化。
- AI 技法整理的已接受条件带有原句范围及条件签名。编辑原文或条件后，对应提示失效；仅供核心账户查看。来源存在不等于条件含义正确，原文仍需人工核对、审核后发布。
- 完成的加密 Agent 研究可追加实际反馈、支持/反例/不明分类和复盘说明，并列展示当时结论与实际反馈。原始回答不被覆盖；复盘不发送云端。完整删除研究仍会删除其复盘。

## 验证与边界

新增测试覆盖第 120 页定位、末尾缺页/空页、范围授权先于调用、条件来源失效、语义阶段独立重试、默认暂停和追加复盘不改原结论。整个流程使用虚构资料，不能视为真实古籍识别或命理预测能力的验证。

既有关键词检索基线保留，不把接通向量搜索等同于召回率已提高。PaddleOCR、专用重排、GraphRAG、通用 Skills/MCP 工具系统、完整因果研究仍未在本轮实现。使用现有受限 Agent 状态流程，没有宣称已采用 LangGraph 或具备完整世界模型能力。

Windows/安卓客户端使用同站点网页时会获得页面更新；本轮未修改安装器和原生外壳版本。
