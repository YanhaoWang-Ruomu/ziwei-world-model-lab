# 本机图文 AI 接入

本轮将 Qwen3.5-4B-Q4_K_M 接到书库问答、技法文字整理和研究 Agent，并提供单张图片阅读入口。轻量浏览器模型与个人 API 仍可选择。

## 使用

1. 初次安装运行 `scripts/setup-local-model.ps1`。模型和程序置于项目旁的 `local-ai-runtime`，不加入源码或部署包。
2. 运行 `scripts/start-local-model.ps1`，打开 `http://127.0.0.1:8788/`。
3. 在本机连接页复制本次连接码，在观星台“账户 → 本机图文 AI”粘贴并验证。连接码仅存当前页面内存，退出账户、切换账户或关闭页面后清除。
4. 在研究对话或 AI 整理助手选择“本机图文 AI”。图片阅读位于研究实验室，单次支持一张 4 MB 以内 PNG/JPEG/WebP，最长边缩到 1600 像素。草稿不自动入库或发布。
5. 不使用时运行 `scripts/stop-local-model.ps1`，释放显存。

需要本轮未上线的完整界面时，运行 `scripts/start-local-ai-preview.ps1`，它会启动本机模型及公开算法副本预览（8879 端口）。该预览与正式网站的账户/资料存储独立。测试端口 8770 仅用于虚构资料验证。

浏览器可能要求允许访问本地网络。手机上的 127.0.0.1 指向手机，不能直接调用电脑模型。本轮没有向局域网或公网开放模型服务，也没有更改 Windows/Android 安装包。

## 结构与边界

- 模型固定为 Unsloth 的 Qwen3.5-4B Q4_K_M GGUF 与 F16 视觉组件；固定源提交与 SHA-256 见 `scripts/local-model-manifest.json`。
- llama.cpp b11669 CUDA 12.4，模型端口只监听 127.0.0.1:8787；带随机内部令牌，关闭请求日志和内置网页。
- 本机桥接端口 8788，检查 Host、网页来源、连接码、正文大小和消息结构。只接受嵌入图片，拒绝图片网址、文件路径、任意工具及任意代理地址。
- 研究 Agent 在本机生成下一步；网站仅接收公开检索词和原文位置。调用工具前保存验证过的决定，工具失败后可以恢复，不重复模型生成。云端流程保留原有计费与恢复约束。
- 引用重新核对公开范围、源文件标识、页码、修订号和原文；不能把逐字引用存在视为解释正确。
- 本机服务不会扫描电脑文件。本轮仅使用明确虚构资料测试，不读取或执行真实私有规则。

## 已验证与限制

2026-10-26：RTX 3070 Laptop 8 GB 显存、约 8 GB 系统内存运行通过；空闲时服务合计显存使用约 5.2 GB（包括其他图形进程）。8192 上下文、单任务、非思考模式。实际长文本和复杂图片速度仍取决于输入。

- 初次 7 项小样本检查通过 6 项；Agent 一次未先检索。保留该失败记录，补充首轮查书工具指引后 7 项通过。
- 检查包括算术、逆命题错误、混杂因素、资料不足、逐字引用、检索后回答、繁体图片数字识别。这不是通用准确率、古籍识别率或因果能力证明。
- 真实本机模型与隔离测试书库 HTTP 流程通过：查找虚构记录 → 搜索 → 读取原文 → 带出处回答。
- 单元及页面交互测试覆盖来源/令牌拒绝、消息限制、停止与旧响应、工具断点恢复、退出后的清理。真实浏览器视觉验收尚未完成：本次浏览器插件缺少其运行组件。

本轮未安装 PaddleOCR-VL，未微调模型，未接入 GraphRAG/DoWhy，也未训练命理预测模型。下一步依据独立失败集评估专用 OCR 和适配训练。

## 复测

`node --test tests/native-ai.test.mjs tests/native-agent-ui.test.mjs tests/local-ai.test.mjs tests/research-agent-ui.test.mjs`

`node scripts/evaluate-local-model.mjs <本机运行目录>` 使用固定虚构文本与 `fictional-vision.png`，生成本地报告并追加历史；不发送付费 API 请求。

隔离测试预览运行后执行 `node tests/native-research.http.mjs`，仅允许 127.0.0.1:8770。
