# 个人 AI 接口与研究对话

个人账户 → 我的 AI 接口：创建至少 12 位独立解锁密码，填写服务商、Base URL、模型 ID 和 API Key，确认一次可能计费的验证请求。验证成功后加密保存，可保存多个配置，选择当前配置、修改、删除或锁定。

本版支持 OpenAI Chat Completions 兼容的文本 / JSON 输出接口，内置百炼北京、新加坡、DeepSeek、硅基流动。模型 ID 可填写；不是所有模型均兼容 JSON 输出。其他服务由运营者审查后通过 `AI_ALLOWED_BASE_URLS` 配置完整 HTTPS Base URL，逗号分隔。不接受任意用户地址、IP、本机服务或重定向。原生 Anthropic / Gemini、音频、图片生成不是本版接口范围。

密钥使用现有 AES-GCM / PBKDF2 本机保险库，独立 namespace，账户散列分区；不进入云端配置数据库、研究册、普通导出或 GitHub。调用时浏览器以同源 POST 发送给应用服务器，服务器将密钥作为授权头转发给选定提供商；没有“密钥从不离开设备”的承诺。退出、切换账户及页面关闭清除内存状态。换浏览器或设备需重新配置，忘记独立密码需重新建立配置空间。

连接验证执行真实的小型 JSON 生成，不只验证 URL 或显示模型列表。401、403、402/429、404、400、超时、输出截断及格式错误分别提示；错误不会回显服务商响应或密钥，不自动重试。所有个人请求使用 `(owner_hash, request_id)` 幂等限制和每账户每日最多 100 次调用（UTC），失败和验证也计入。该限制不是人民币费用封顶，请在服务商配置预算。本站统一千问仍独立保留原有 5 元预算逻辑。

书库中整理原文后，AI 助手可选“我的 API”。AI 研究对话位于研究室顶部，模型实际选择检索、澄清或回答三种受限操作，每轮最多四步；引用必须与服务器重新读取的公开原文匹配。它不能访问授权级或私密材料，不能执行命盘公式、自动审批或发布。程序只验证引用存在，不保证语义解释正确。

研究可选择加密保存到本机 AI 研究册。每次发出请求前写检查点；成功后保存工具事件和来源。重新打开可恢复已完成的状态。结果未知的请求不自动重发；用户可明确创建新研究。记录保留模型配置标识但不含密钥；恢复时复核材料权限与版本。切换个人 API 后，旧研究不能混用新模型继续调用。

验收采用虚构花盆日志、假密钥和模拟提供商响应，不使用真实技法。单元测试覆盖账户额度隔离、幂等、接口地址限制、错误脱敏、原文权限及 Agent 操作限制。真实服务连通性由每位用户在设备上填写密钥后验证，不将模拟通过声称为真实服务已连接。

接口依据：[百炼](https://help.aliyun.com/en/model-studio/base-url)、[DeepSeek](https://api-docs.deepseek.com/en/)、[硅基流动](https://docs.siliconflow.cn/docs/api/chat-completions-post)。
