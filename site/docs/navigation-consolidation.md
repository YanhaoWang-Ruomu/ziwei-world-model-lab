# 六入口工作区整合

本次将既有页面归入六个主入口，保留原 hash 地址、数据接口与权限检查。

| 主入口 | 原有页面 |
| --- | --- |
| 星辰与命盘 | 命盘、观星、规则推演 |
| 资料库 | 阅读与检索、上传与管理、本机私密 |
| 技法中心 | 卡片、编辑与测试、我的提交 |
| 研究室 | 状态、事件、分支推演与复盘、演示沙盘 |
| 社区 | 投稿、评论、收藏、举报入口 |
| 管理中心 | 分类审核、账户授权、历史记录 |

账户和下载仍可独立打开。受限入口显示锁，服务器继续检查每项权限。特殊用户只能在自己的提交编辑上下文中进入规则草稿；其余核心工作台不开放。

## 功能修正

- 技法卡统一搜索入口与来源筛选；自编编辑器搬入编辑与测试。
- `scope=mine` 明确隔离本人摘录提交与核心审核列表；自编技法采用独立本人查询。
- 审核中心按技法、摘录、社区、举报分类，待办数量来自现有数据库。
- 历史列表汇合已有技法快照、文稿校订、摘录提交及决定、社区审核与举报处理。不会虚构尚未记录的旧操作；技法的完整快照仍走原核心权限接口。
- 研究室页内切换保留未保存表单；时间线可直接保存同一份状态表单。
- 无数据库迁移，无清理、搬移或重置用户数据。

## 验证

只使用公开副本、公开算法适配器和虚构资料。121 项单元/交互检查、62 项研究社区接口检查、50 项富文本附件与评论检查、38 项账户命例隔离检查通过。公开构建通过。

新增测试验证六入口和旧路由、降级后权限锁、特殊账户草稿入口、核心本人提交、统一筛选、研究表单保留，以及历史分页同秒事件不遗漏。此次浏览器控制工具不可用，未声称完成真实浏览器截图或手机实机验收。

Windows 与 Android 客户端使用同一线上页面；本次没有改变原生安装包代码与版本。线上界面更新随重新打开或刷新客户端生效。
