# 公开书库与联网联合研究

本批实现位于“AI 研究对话 → 书库＋联网联合查询”，沿用金箔绢画样式，不增加一级导航。

## 使用流程

1. 登录账户，填写公开研究问题；可选单本公开材料、最多三组检索词。
2. 先查书库：保留原有简繁处理、近似检索和关键词检索，使用 RRF 合并多组结果，最多返回六段原文。此步骤不调用付费模型。
3. 可选择加密保存；先解锁本机 AI 研究册。保存后可刷新页面、重新解锁并恢复到书库检查点。
4. 勾选联网费用确认，使用当前已验证的个人北京百炼 qwen-plus / qwen-flash 配置。可限定最多三个网站域名及最近 7 / 30 / 180 / 365 天。
5. 查看联合草稿、书库原页与网页来源。恢复完成记录时不再次调用模型。

没有公开书库命中时也可联网；界面明确显示零段书库依据。不会静默切换为无来源的模型记忆回答。

## 来源检查的边界

- 书库：服务器重新核对公开权限、文件指纹、页码、文本来源、校订版本与字符位置；引用片段由服务器重新取得，不信任浏览器传来的片段。
- 网页：采用 DashScope 原生接口的来源列表及 `[ref_n]`，过滤危险链接、不在限定域名内的链接以及无效引用编号。只有书库编号而无有效网页引用的回答不能作为联网成功。
- 这不等于逐页下载网页全文，也不等于逐句事实核查。界面保留明确提示和查询时间。来源正文不会被作为代码执行，输出以纯文本展示。
- 本批是多查询词结果融合；不是新增专用神经重排器。原有单本 E5 语义研究仍保留于原研究流程。

## 账户、费用和恢复

- 仅处理用户明确确认可公开的问题，以及服务器允许公开的材料。不读取真实私密规则，也不调用私有安星模块。
- 密钥仍按账户保存在本机加密空间；调用时经本站服务器瞬时转发到固定北京百炼原生地址。不保存密钥。
- 联网调用与个人接口验证、问答共用每账户每日 100 次请求上限（UTC）；**不是人民币硬限额**。模型与搜索费用以服务商账单为准。
- 发出请求前保存请求编号和运行中检查点；同账户同编号禁止再次发送。超时、取消或无效响应均不自动重试，也不声称没有计费。
- 结果加密保存在本机研究册，可导出和恢复加密备份。服务器的新表 `discovery_receipts` 只保存账户哈希、请求编号、结果哈希和时间，用于阻止跨账户恢复及篡改结果；不保存问题和回答全文。
- 检索结果仅在下次使用时重新检查仍公开。历史网页是当时服务商返回的来源快照，恢复不代表页面现在仍存在或内容未变。

## 对两个参考项目的取舍

- [OpenManus](https://github.com/FoundationAgents/OpenManus)：借鉴“明确步骤、有限工具、保存中间结果”。其默认 Manus 包含代码执行、文件编辑和浏览器 MCP 等工具，本应用本批未安装这些通用工具，不让 Agent 获得私有目录或任意脚本执行权。
- [Alignify 知识库页](https://alignify.co/zh/tools/knowledge-base)：这是知识库方案介绍/比较页面，不是可以直接嵌入的开源检索引擎。本批借鉴材料范围、出处和检索组合的产品设计。

千问调用参数与来源字段依据 [百炼联网搜索官方文档](https://help.aliyun.com/zh/model-studio/web-search)。原生 DashScope 用于返回搜索来源和引用编号，未把 OpenAI 兼容文本回答假定为相同协议。后续服务商需单独适配其真实来源结构，不能直接复用某家的字段。

## 验证与上线

`tests/discovery.test.mjs` 覆盖原生协议、权限前后检查、来源、去重、请求限额和恢复凭据；`tests/discovery-ui.test.mjs` 覆盖检查点、费用确认、断网、账户切换、跨页互斥及安全显示。所有材料均为虚构园圃记录，服务商响应为模拟；没有使用用户密钥进行付费测试。

本轮公开副本构建和 51 项相关测试通过。`tests/discovery.http.mjs` 在 8770 端口、独立虚构测试库上通过：真实 Worker / D1 迁移、繁体第 120 页召回、登录与材料权限、新恢复凭据接口。测试库位于 `.wrangler/persistence-test/discovery-20261026`，不连接用户数据。Browser 插件因缺失运行文件未能启动，因此尚无实机浏览器视觉验收；界面交互由 Happy DOM 验证。

部署前需应用 `0018_discovery_receipts.sql`。新增功能不改变 Windows / Android 外壳版本；发布网页后，联网客户端加载更新。实际服务商模型权限、账单与联网可用性需要用户解锁配置后试用。
