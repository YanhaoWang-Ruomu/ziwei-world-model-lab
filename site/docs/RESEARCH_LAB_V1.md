# 图文检索试验与研究验收

本轮继续使用已经接入的 Qwen3.5-4B-Q4_K_M。本轮没有安装 Qwen3-VL Embedding/Reranker、PaddleOCR-VL、LangGraph 或知识图谱，也没有训练模型权重。

## 使用入口

- 书籍与文章 → 原页图文比较：登录后刷新公开材料，填写问题与连续 1–8 个 PDF 文件页码，连接本机图文 AI 后开始。只读取选定页面，不扫描本机文件。即使该页 OCR 为空，只要影像存在，仍可比较图像。
- 使用已有 BM25 分数作为文字对照，用本机视觉模型判断每页与问题的相关等级，再以 RRF 合并候选顺序。这是视觉模型逐页判断，不是图像向量索引。相关等级不是概率，图像识别的引文不视为已校对原文。
- 标记每页相关或不相关后，比较本轮前 3 个候选的召回。必须全部处理且全部标记；未标记不能当负例，没有正例不计算召回。该指标只描述当前所选小样本，不推广为整库效果。
- 研究实验室 → AI 研究对话：增加进度概览、书页比较问题带入及报告导出。导出前再次核对原文权限、版本及逐字引用。报告包含问题、过程、来源、待确认项和后续反馈，导出到当前设备，不自动发布。
- 研究实验室 → 研究评测：7 个固定虚构题，分别检查引用、文献冲突、拒答、逻辑与因果边界、图像读数、工具中断恢复。每轮最多 8 次本机模型调用，错误和未通过单列；人工评价追加保存。

## 保存与隔离

两类新记录使用现有按账户隔离的 AES-GCM 本机研究册。勾选保存且解锁后，逐页或逐题写入，保存失败不继续下一步。加密备份包含新记录种类。多标签页使用互斥锁与修订号，已完成页与已完成题恢复时不重复处理。

服务器图文端点只允许已登录账户读取当前公开材料，影像请求绑定原文版本；读取与恢复时再次检查公开范围和版本。响应使用 private/no-store。退出、锁定、断开本机模型、删除材料会清除页面内容，并取消后续工作。模型图片不写入研究册，也不发往云端 AI。用户输入公开研究问题；真实私有材料不进入此入口。

## 验收（2026-10-27，悉尼）

- 公开框架自动测试：242 项通过，包括新的断点恢复、保存失败、引用修订、公开权限、迟到结果丢弃、人工样本标记及页面交互检查。
- 公开副本构建通过。原项目的私有安星规则未读取或执行。
- 实际本地 Worker、迁移后的 D1 与 R2 通过 HTTP 联合检查：第 120 页 OCR 为空时仍可取得已保存影像；登录、版本绑定与禁止缓存生效。R2 使用虚构字节夹具，图像内容理解另由真实 PNG 模型测试验证。
- `node evaluations/run-research.mjs <报告路径>`：实际本机 Qwen3.5-4B 运行，7/7 题机械检查通过；累计约 6.1 秒（非性能保证）。另外一张固定虚构中文图片的图文试验成功读出甲盆 20、乙盆 30、合计 50 毫升。
- 原生模型实测只使用公开虚构样本，不代表古籍 OCR 准确率、普遍推理能力或因果有效性。人工复核仍必需。
- 浏览器插件因缺少 browser-service 模块未能连接；页面交互采用 Happy DOM 验证，未完成真实浏览器截图验收。

## 后续模型对照

先用公开、授权的繁体竖排样本记录正确页与漏检，再将 Qwen3-VL-Embedding/Reranker 2B 作为独立候选测试。保持问题集、候选页面、人工标记与硬件条件一致，记录显存、延迟、错误与召回差异；分开保留调试题与未见验收题。更换模型时新建一轮记录，不能复用旧结果冒充新模型表现。
