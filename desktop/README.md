# 观星台 Windows 桌面版

Windows 10 / 11，64 位 x64。该版本通过独立桌面窗口连接观星台正式网站，需要联网。

## 安装与使用

运行 `release/GuanXingTai-Setup-1.0.0-x64.exe`，选择安装目录。可创建桌面及开始菜单快捷方式。安装到当前用户，无需将个人账户资料放在安装目录。

- 用原网站用户名和密码登录，账户权限、云端命例、书籍、技法卡及历史记录共用同一服务。
- `F11` 全屏；`Ctrl + +` 放大，`Ctrl + -` 缩小，`Ctrl + 0` 恢复大小。
- 网络不可用时显示重连页，恢复网络后点击重新连接。
- 导出命例、书库加密备份等文件时会弹出保存位置选择框。
- ChatGPT 登录使用独立的隔离登录窗口；第三方身份服务是否允许嵌入式浏览器由对方决定，如遇限制，请使用网站用户名与密码登录。

## 本机资料

固定保存位置：`%APPDATA%\GuanXingTai`。登录凭据由 Chromium Cookie 存储管理，不另建明文密码文件。本机私密书库沿用网站的加密保存功能，位于桌面软件独立的 IndexedDB 空间。

浏览器与桌面软件的本机存储不同。迁移书库：在原浏览器导出加密备份，在桌面版使用同一账户登录，进入本机书库后导入备份，并输入原备份密码。

覆盖安装新版保留上述目录。卸载不会主动删除本机资料。不要手动清理此目录；重要材料请定期在书库中导出加密备份。

## 更新与分发

网站功能从正式网站加载，随网站更新。桌面程序本体当前使用手动更新：发布新版安装包后，用户下载并覆盖安装。此版本不包含自动下载更新服务。

本次生成的是未签名安装包，未提交 Microsoft Store。Windows 可能显示未知发布者。正式广泛分发前应使用发布者的代码签名证书重新构建；不要要求用户关闭安全软件。

安装包仅包含桌面程序代码、图标与 Electron 运行环境；不包含网站源代码、服务器私有安星算法、PDF、上传文件、用户数据库、测试资料或本机书库。

## 开发和验证

1. `pnpm install --frozen-lockfile`
2. PowerShell 设置 `$env:electron_config_cache = Join-Path (Get-Location) '.cache\electron'`，然后 `node node_modules/electron/install.js`。
3. `pnpm test` 验证导航边界和文件名处理。
4. `pnpm test:desktop` 使用独立测试目录和本地虚构网页验证桌面功能。测试不会连接正式网站或读取真实书库。
5. `pnpm dist` 生成 x64 安装包。

如需重建图标，可用装有 Pillow 的 Python 运行 `scripts/make-icon.py`。生产入口 `app/main.cjs` 不接受自定义网站地址或测试参数；测试从单独入口运行，且不会打入安装包。

## 1.0.1 更新流程
启动 7 秒后检查公开下载清单；也可从“帮助 → 检查更新”触发。确认后下载，校验大小和 SHA-256，再单独确认安装。安装前保留登录存储并退出，NSIS 覆盖当前安装位置后重新启动。断网、取消和校验失败不会执行安装包。Windows 仍为未添加发布者签名的版本。
图标作为独立 ICO 资源打包；窗口绑定统一 AppUserModelID，启动时修正已有观星台快捷方式的图标与路径。
后续发布需提高 package.json 版本、重建安装包、运行 site/scripts/prepare-releases.mjs 并发布网站。已经发布的版本号与安装包内容不得覆盖复用。1.0.0 需先手动安装本版，之后才支持启动检查。
