# 观星台 Android 1.0.0

安装包：`release/GuanXingTai-1.0.0.apk`，Android 8.0 及以上。需要联网，以及保持更新的 Android System WebView。该包没有原生架构依赖，可用于常见 ARM/ARM64 安卓手机和平板。

使用现有网站账户登录，继续使用云端命例、书籍和已授权技法卡。APK 不包含私有安星算法、书籍 PDF、账户记录或网站服务端代码。

## 安装及更新

下载 APK 后按系统提示安装；不同品牌、地区的设备可能出现来源授权、开发者验证等提示。本版本未在应用商店发布。之后使用相同签名的新 APK 覆盖安装，不要先卸载。

本机私密书库与浏览器保存空间独立。先从原浏览器导出加密备份，再在应用书库中导入。安卓卸载应用或清除应用数据会删除本机书库，因此务必定期导出备份。系统云备份已关闭，避免将本机材料自动带入设备云备份。

系统返回键：先返回上一页，根页面确认后退出。网页上传使用系统文件选择器；导出文件使用系统保存对话框。仅申请联网相关权限，不申请麦克风、摄像头或整个存储空间权限。

用户名和密码登录使用原网站服务。ChatGPT 登录在单独窗口中进行；第三方服务可能限制 WebView 登录，此时请使用网站账户登录。

## 签名密钥

正式发布密钥在本项目 `.signing` 目录中，包括 `release.p12` 和密码文件。请将整个目录安全备份到你控制的离线存储，勿上传网站、发送给他人或提交代码仓库。后续版本必须使用此密钥，丢失后无法作为原应用直接升级。

构建脚本只在密钥不存在时创建密钥，已有密钥会继续复用；不会自动更换。

## 构建和校验

使用官方 Adoptium JDK 17、Android SDK 35 / Build Tools 35.0.0。工具包下载会核对官方提供的校验值。

1. `node scripts/setup.mjs`
2. 使用带 Pillow 的 Python 运行 `scripts/extract.py`（图标沿用桌面版成品）。
3. PowerShell 运行 `scripts/build.ps1`。

本次验证包括编译、APK v2/v3 签名、应用标识、最低系统版本、权限及导航策略检查。本机未连接安卓设备，尚未完成安卓实机安装与 WebView 交互验收。首次安装后应核对登录、文件上传/导出、书库备份恢复及横竖屏显示。

## 1.0.1 更新流程
启动时检查公开下载清单；下载页内提供“检查当前安卓应用更新”。确认下载后校验大小、SHA-256、包名、递增 versionCode 和原签名，再打开系统安装界面。首次需要用户允许观星台安装应用，最终安装由系统要求用户确认，不能绕过系统静默安装。
后续版本需同时提高 AndroidManifest.xml 的 versionName 与 versionCode，使用原 .signing 密钥构建，再生成并发布网站下载清单。1.0.0 用户先手动覆盖安装本版。系统安装交互尚待安卓实机验收。
